# 40 Force — архитектура

> Источник решений: docs/40-force-research-log.md (сессии 1–3 и решения владелицы).
> Этот документ описывает, как строим. Почему — в журнале.

## Принципы

- Телефон — источник правды. По умолчанию всё локально; облако — только по opt-in (3 тумблера согласий).
- Ядро логики отделено от интерфейса: пакет `packages/core40` на чистом Dart без Flutter-зависимостей. Вся статистика, модель дня и квоты живут там и покрываются тестами без эмулятора.
- LLM — только черновик по голосу и поддерживающий спутник, за одним сменным серверным слоем (Meta Model API первым провайдером). Модель не ставит диагнозы, не меняет данные без экрана подтверждения, не участвует в кризисном экране.
- Язык продукта — только разрешённый список из сессии 1 журнала.

## Слои

1. **core40 (Dart, без Flutter)**: сущности, модель дня, движок карточек, квоты. Чистые функции, детерминированные, тестируемые.
2. **app (Flutter)**: экраны календаря, check-in, графиков, карточки дня, PDF на устройстве, локализация EN/ES/RU/pt-PT. Только показывает результаты ядра.
3. **sync (позже)**: опциональный облачный бэкап и серверная аналитика по согласию; смена LLM-провайдера настройкой сервера.
4. **extension (если успеем в MVP)**: попап быстрого check-in + полноэкранные графики на том же коде графиков; демо в режиме разработчика.

## Сущности (ядро)

- `TrackingTarget` — отслеживаемый показатель (сон, энергия, настроение пользователя). Базовые всегда доступны и в квоту не входят: цикл (`CycleDay`), физическая форма, ментальная форма.
- `FactorEvent` — фактор-событие дня (кофе, алкоголь, поздний ужин и т.п.).
- `Medication` (+ расписание и отметки приёма, фото) — отдельная сущность, квоту FactorEvent не расходует.
- `CheckIn` — утренний/вечерний: текст, голос (черновик LLM после правки), значения таргетов, факторы.
- `SleepInterval` — сон; ночь принадлежит утру, которым заканчивается.
- `DayData` — агрегированный день для статистики: дата пробуждения, значения таргетов, факторы дня.

## Модель дня

День начинается с пробуждения. Ключ дня = календарная дата пробуждения (`dayKeyForWake`). Сон, закончившийся утром дня D, относится к дню D. Утренний check-in закрывает сон.

## Движок карточек

- Графики строятся с 1-го дня; при малом числе точек — пометка «данных пока мало».
- «Ранние наблюдения» — с 5–6 дней данных: только описательные совпадения по отмеченным дням, без лагов, с пометкой «раннее наблюдение, данных пока мало».
- Полные карточки — с 14 дней: базовый уровень, дни с фактором, N наблюдений, лаги 0–3 дня, окна 3/7 дней, «другая возможная причина». Фактор допускается к полному расчёту при минимуме 5 дней с фактором (порог в `CardEngine.minFactorDays`).
- Ранжирование по силе сдвига относительно базового уровня; слабый сдвиг (ниже `minDelta`) не показывается — защита от шума при 100 факторах.
- Карточка — гипотеза о совпадении по времени, не причина. Постоянная пометка: совпадение по времени не показывает причину.

## Квоты (решения владелицы)

| Ресурс | Free | Paid |
|---|---|---|
| Свои TrackingTarget сверх базы | 3 | 30 |
| FactorEvent | 8 | 100 |
| Новые карточки | 1 в день | все факторы с данными |
| История графиков | 90 дней | вся + сравнение периодов |
| Голос после 14-дневного триала | 1 check-in в день | 20 в день |
| AI-спутник | 5 ответов в день | 50 в день |

Анти-абьюз триала: до 5 голосовых check-in в день, до 10 минут аудио в день, одна запись до 3 минут. Все числа — константы в `quotas.dart`, меняются без переписывания логики.

## Безопасность и приватность

- Локальное хранение: SQLite + SQLCipher (веха приложения). Удаление серверных копий — до 30 дней после отзыва согласия.
- Кризисный экран: детерминированный, на устройстве, офлайн, без модели; страна фактического проживания, не язык. Номера — только из подтверждённых первоисточниками (см. журнал, сессия 3).
- Скрытая терапевтическая роль запрещена: спутник открыто представляется AI, не врачом и не терапевтом.

## Что не входит в эту веху

Flutter-оболочка при отсутствии SDK в текущей среде, Drift/SQLCipher, облачный синк, реальные вызовы Meta Model API (слой с заглушкой), расширение Chrome, PDF-рендер.
