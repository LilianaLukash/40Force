# 40 Force

Wellness-дневник самонаблюдения для женщин 40+: календарь, check-in текстом и голосом, графики с первого дня, честные карточки совпадений по времени, бесплатный PDF врачу с логотипом приложения.

Решения и исследования: [docs/40-force-research-log.md](docs/40-force-research-log.md). Архитектура: [docs/architecture.md](docs/architecture.md).

## Структура

- `packages/core40/` — ядро на чистом Dart (модель дня, движок карточек, квоты), без зависимости от Flutter.
- `app/` — Flutter-приложение (календарь, check-in, графики, карточка дня) поверх ядра, демо-данные на 20 дней.
- `docs/` — журнал решений и архитектура.

## Тесты ядра

Нужен Dart SDK 3+:

```sh
cd packages/core40
dart pub get
dart test
dart analyze
```

## Статус

Веха 1: ядро и тесты. Дальше: Flutter-оболочка (календарь, check-in, графики, карточка дня), локальное хранение SQLite + SQLCipher, сменный LLM-слой (Meta Model API), PDF на устройстве, при успехе по времени — Chrome-расширение для демо.
